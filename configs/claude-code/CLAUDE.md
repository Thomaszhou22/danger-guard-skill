## Safety Rules

### Forbidden Operations (NEVER execute these)

- `rm -rf /`, `rm -rf /*`, `rm -rf ~`, `rm -rf /Users`
- `dd if=/dev/zero of=/dev/sd*`, `dd if=/dev/urandom of=/dev/sd*`
- `mkfs.*` (any filesystem format)
- `chmod -R 777 /`, `chown -R root:root /`
- Fork bombs: `:(){:|:&};:`, `fork while fork`
- `shutdown`, `reboot`, `halt`, `poweroff`
- `curl | sh`, `curl | bash`, `wget | sh`, `wget | bash`

### Git Safety

- NEVER use `git push --force` or `git push -f` on shared branches
- NEVER use `git reset --hard` without explicit user confirmation
- NEVER use `git clean -fd` or `git clean -fdx` without confirmation
- Use `git push --force-with-lease` instead of `--force` when possible

### Docker Safety

- NEVER run `docker system prune -a --volumes` without confirmation
- NEVER run `docker volume prune -f` without confirmation
- NEVER run `docker-compose down -v` without confirmation

### Database Safety

- NEVER execute `DROP TABLE`, `DROP DATABASE`, or `DROP SCHEMA` without confirmation
- NEVER execute `TRUNCATE TABLE` without confirmation
- NEVER execute `DELETE` without a `WHERE` clause without confirmation
- NEVER execute `UPDATE` without a `WHERE` clause without confirmation

### Required Confirmations

Before executing any of the following, explain the risks and ask for explicit confirmation:

- Any command with `sudo`
- Any file deletion outside of `/tmp/` or `.Trash/`
- Any permission changes (`chmod`, `chown`)
- Any system configuration changes (`/etc/`, `/var/`, `/usr/`)
- Any global package installation (`npm install -g`, `pip install` outside venv)
- Any `docker run --privileged`
